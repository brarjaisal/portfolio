# To-Do App (React)

A simple, clean task management application built in React to practice core front-end concepts.

## 🎯 Goals of this project
- Learn React components and state
- Work with controlled inputs
- Persist data using localStorage
- Build an accessible, keyboard-friendly UI
- Maintain a clean folder structure

## ✅ Planned Features
- Add, complete, and delete tasks  
- Filter tasks: All / Active / Completed  
- Save tasks to localStorage  
- Responsive layout  
- Minimal, readable design  

## 🛠 Tech Stack
- React (Vite)
- JavaScript
- CSS

In progress — initial setup complete.
