# Expense Tracker (Vanilla JavaScript)

A clean and responsive expense tracker built with HTML, CSS, and JavaScript.  
Users can add expenses with a category and date, filter by time range, and keep data saved with localStorage.

## Live Demo
https://simplysmartexpensetracker.netlify.app/

## Features
- Add expenses with name, amount (supports decimals), category, and date
- Filter by:
  - All
  - Today
  - This Week
  - This Month
- Delete expenses instantly
- Total updates dynamically based on active filter
- Data persists using localStorage
- Mobile-friendly responsive UI

## Built With
- HTML
- CSS
- Vanilla JavaScript
